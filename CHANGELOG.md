# Changelog

All notable changes to Mantis Calculator are documented here.

## [1.0.0] — 2026-08-04

### 🎉 Initial Release

#### Added
- **Basic Calculator** — Standard arithmetic with parentheses
- **Scientific Calculator** — Trigonometric, logarithmic, power & root functions with 2nd-mode toggle and DEG/RAD switch
- **Programmer Calculator** — Real-time base conversion (DEC, HEX, OCT, BIN) with bitwise operations
- **Unit Converter** — Length, Weight & Temperature conversions
- **Calculation History** — Auto-saved history with Room database, reverse-chronological view
- **Settings** — Dark/Light theme toggle, haptic feedback control, About section
- **Bottom Navigation** — Seamless tab switching between all 6 modes
- **Material 3 Design** — Custom Mantis Green theme with dark and light color schemes
- **Splash Screen** — Android 12+ splash screen API integration
- **Haptic Feedback** — Tactile button press feedback
- **100% Offline** — No internet, no tracking, no ads
